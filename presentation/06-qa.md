# 발표 — 예상 질문과 답

기준: 2026-11-20, 최종 서버 <https://nlpwizard.eta.pyhub.kr> · 작업용 서버 <https://54-252-22-31.sslip.io> — app `v0.1.6` · model `m20261120-24`.

답은 짧게, 근거는 링크로. 모르는 것·안 한 것은 그대로 말한다.

## 설계

| # | 질문 | 답 | 근거 |
|---|---|---|---|
| 1 | 왜 Lightsail 인가? | 과제 요구(R1)다. 정액 요금이라 비용이 예측된다. 같은 리전 버킷에 키 없이 붙는다(리소스 액세스). GPU 가 필요 없는 CPU 모델이라 작은 인스턴스로 된다 | [R1](../requirements/R1-lightsail.md), [ADR-007](../decisions/ADR-007-region-instance.md), [ADR-005](../decisions/ADR-005-student-model-snapshot.md) |
| 2 | LLM 을 바로 서빙하지 않은 이유는? | 서버에 GPU 가 없다. LLM 판정을 교사 라벨로 받아 CPU 학생 모델(해싱 TF-IDF + 로지스틱 회귀, ONNX)로 증류했다 | [ADR-005](../decisions/ADR-005-student-model-snapshot.md) |
| 3 | 왜 AWS 계정이 둘인가? | 일을 둘로 나눴다(2026-11-19). R1~R5 는 작업용 계정 서버(54.252.22.31)에서 마음껏 만들고 지운다. 발표용 최종 서버(nlpwizard.eta.pyhub.kr)는 다른 AWS 계정이라 버킷을 키 없이 못 읽는다 — 그래서 같은 Actions 실행 산출물로 검증된 모델 판을 넘긴다(PR #45), 최종 결과만 마지막에 올린다 | [R1](../requirements/R1-lightsail.md) 서버 절, [자원 정리](../runbooks/teardown.md) ①·③ |
| 4 | 최종 서버는 어디까지 됐나? | 배포 준비만 끝났다. `FINAL_ENABLED` 를 켜기 전엔 아무 잡도 돌지 않는다. 러너 이름표도 따로(`final`)라 작업용 서버 잡과 안 섞인다. 서버 접근 대기 중 | PR [#45](https://github.com/metahomo/miniproject5_kms/pull/45)(열림) |

| 9 | F1 0.9609 는 정답률인가? | 아니다. 교사(LLM) 라벨과의 일치도다. 사람 검수 라벨이 0편이라 지금은 이게 최선이다 | [ADR-006](../decisions/ADR-006-gate-parity.md), 이슈 [#12](https://github.com/metahomo/miniproject5_kms/issues/12) |
