# ADR-006 게이트와 parity 기준 (잠정)

## 배경

결정 이슈 [#12](https://github.com/metahomo/miniproject5_kms/issues/12)(시험지)·[#13](https://github.com/metahomo/miniproject5_kms/issues/13)(지표·임계값·parity)이 열려 있다. 연구자 외출 중 사령관이 잠정값을 정해 워크플로가 돌게 했다. 값은 환경변수라 코드 수정 없이 바꿀 수 있다(`GATE_MIN_F1`·`GATE_MARGIN`·`GATE_MAX_DROP`·`PARITY_TOL`).

## 선택지 — 시험지 (#12)

| 선택지 | 장점 | 단점 |
|---|---|---|
| 사람 검수 라벨만 | 정답에 가장 가깝다 | Mac 의 KMS 에는 사람 검수 라벨이 0편(Windows 의 10편은 옮겨오지 않음) — 지금은 불가 |
| **교사 라벨 고정 분할(열쇠 해시 20%)** | 지금 바로 178편. 새 데이터가 와도 기존 시험 문항이 바뀌지 않는다 | 교사와의 일치도일 뿐 — 교사가 틀리면 같이 틀린다 |
| 교사 라벨 중 확신 높은 것만 | 잡음이 적다 | 교사가 relevance 를 거의 0.3/0.7/1.0 으로 내 "확신"의 뜻이 약하다 |

## 결정 (잠정)

- **시험지**: `paperclf/labels.py split_of` — 열쇠 해시 % 5 == 0. uncertain 은 뺀다. 2026-11-19 스냅숏 기준 178편(include 140).
- **지표**: include 클래스 F1(확률 0.5 기준).
- **게이트** — 셋 다 넘어야 승격(`training/validate_model.py`):
  1. F1 ≥ 0.80 (하한)
  2. F1 ≥ 기준선(전부 include 라고 답할 때의 F1) + 0.05 — 2026-11-19 기준선 0.8805 이므로 사실상 0.93
  3. 운영 모델 카드가 있으면 F1 ≥ 운영 F1 − 0.02
- **parity**: 원본 sklearn 과 서빙 이미지(ONNX)의 p(include) 최대 절대 차이 ≤ 1e-5. 게이트 시험지(특징 입력)와 고정 예문 12편(원문 입력 — 특징 계산까지 확인) 둘 다.

## 확인한 사실 (2026-11-19, 로컬)

| 모델 | 학습 편수 | 게이트 F1 | 결과 |
|---|---|---|---|
| 전체 데이터, C=4 | 674 | 0.9603 | 통과 |
| 데이터 10% | 67 | 0.9333 | 통과(경계) |
| 데이터 5% | 33 | 0.9021 | **실패** — 기준선+0.05 미달 |
| 데이터 2% | 13 | 0.9013 | **실패** |

- C 는 1·4·16 을 시험했으나(F1 0.938 / 0.960 / 0.964) **게이트 시험지로 고르면 시험지에 과적합**하므로 미리 정한 4 를 유지했다.
- ONNX 차이: 5.4e-7 (게이트 178편), 원문 12편 1.8e-7.

## 영향

- 게이트 시연(강의 02 "일부러 덜 학습시켜 보기"): `model` 워크플로를 `data_fraction=0.05` 로 수동 실행하면 train 잡에서 멈춘다.
- 사람 검수 시험지가 생기면 시험지만 바꾸고 기준은 다시 정한다.
