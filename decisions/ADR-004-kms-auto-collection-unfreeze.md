# ADR-004 KMS 참고문헌·운영 DB 동결을 자동 수집에 한해 푼다

## 배경

연구자가 2026-11-18 "KCI·OpenAlex 둘 다 컴퓨터가 켜 있는 동안 참고문헌 및 자료를 자동 수집하게 한다"를 지시했다. KMS 지침 18절은 운영 DB 와 참고문헌(KCI 포함, 009 전체)을 "사용자가 다시 언급할 때까지 읽기만" 하도록 동결하고 있어, 사령관이 범위를 확인했다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| 동결 유지 | 운영 DB 변화 없음 | 자동 수집 불가 |
| **자동 수집에 한해 해제** | 새 논문이 쌓여 [R3](../requirements/R3-auto-train-validate.md) 재학습 재료가 생김. 스키마·기존 데이터는 보호 | 운영 DB 가 계속 커짐 |
| 전면 해제 | 제약 없음 | 스키마·기존 데이터·009 정규화까지 열림 |

## 결정

연구자 선택(1번): 18절 동결을 **자동 수집 — 기존 수집 파이프라인으로 데이터를 쌓는 것 — 에 한해** 푼다.

- 허용: 수집 파이프라인이 운영 DB 에 새 논문·저널·실행 기록을 추가하는 것.
- 계속 금지: 스키마 변경·마이그레이션, 기존 데이터 수정·삭제, 009(영문 메타데이터·Crossref·DOI 확인) 작업.
- 이 결정만으로는 KMS 저장소를 고치지 않는다. [AGENTS.md](../AGENTS.md) 1절의 "KMS 저장소 읽기 전용" 예외는 선택되지 않았다(2번 미선택). `.env` 는 열지 않는다.

## 근거 (연구자의 언어로 채울 칸)


## 영향

- 자동 실행(KMS M6)과 KCI 수집 소스를 구현하려면 KMS 저장소 쓰기 예외, 진행 순서, 실행 주기를 따로 정해야 한다.
- KCI 수집 어댑터는 아직 없다. 현재 `kms/sources/kci.py` 는 영문 메타데이터 조회용(M3)이고 엔드포인트가 공식 문서로 확인되지 않은 가정 구조다.
